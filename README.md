# Exam-CCAO-F

A local practice platform for the **Claude Certified Associate – Foundations (CCAO-F)** exam.

- 1,000-question bank, split across the 7 exam domains by blueprint weight
- Timed mock exams: 60 questions, 120 minutes, auto-submit at 00:00, pass mark 72% (≈ 720/1000 scaled)
- Each mock prefers questions you haven't seen yet; question and option order is shuffled every time
- Results with per-domain breakdown and full answer review with explanations
- Progress dashboard: score trend, mock history by day, domain strength, bank coverage
- Domain drills with instant feedback
- Progress is saved in your browser; use **Save progress backup** / **Restore from backup** to move it

## Run it

Open `index.html` in any modern browser. No install or server needed. Keep the `questions/` folder next to `index.html`.

```bash
open index.html
```
